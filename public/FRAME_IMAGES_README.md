# Frame Images for FarStick

This directory should contain the frame images used in the Farcaster Frame:

## Required Images:

1. **frame-image.png** (1200x630px, 1.91:1 aspect ratio)
   - Main frame image showing the game title and characters
   - Should include "FarStick" title
   - Show game characters or dungeon scene
   - Include call-to-action text like "Enter the Dungeon!"

2. **battle-frame.png** (1200x630px, 1.91:1 aspect ratio)
   - Battle scene frame image
   - Show player vs enemy combat
   - Include battle UI elements
   - Action-oriented design

## Image Requirements:
- Format: PNG or JPEG
- Size: 1200x630 pixels (1.91:1 aspect ratio)
- File size: < 1MB recommended
- High contrast and readable text
- Optimized for social media sharing

## Creating the Images:
You can create these images using:
- Game screenshots from the PixiJS application
- Design tools like Figma, Canva, or Photoshop
- AI image generators with the game's visual style
- Screen captures of the actual game scenes

For now, placeholder images should be created or you can use a simple colored rectangle with text as a temporary solution.
